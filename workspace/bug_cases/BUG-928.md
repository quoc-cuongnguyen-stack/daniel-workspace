# BUG-928: City name missing from desktop profile header & map overlay after location update

> **Status:** ✅ Fixed
> **Date Found:** 2026-08-07
> **Date Fixed:** 2026-08-07
> **Project:** SSL (Frontend)
> **Severity:** 🟡 Medium

---

## 🔍 Description

In the View Profile page, updating a user's location set the country and city correctly in the database and Edit Location modal. However, the desktop profile header omitted the `City` name, displaying only `Country` on the right-side map card overlay and hiding the `City, Country` text entirely under the desktop user bio section.

## 🔄 Reproduction Steps

1. Open Edit Location modal on profile page.
2. Select a country (e.g. Ireland) and city (e.g. Kentstown).
3. Click Update Location.
4. Observe the profile header: The right-side map card heading showed `Ireland` instead of `Kentstown, Ireland`, and the desktop bio section omitted the location text.

**Expected behavior:** Profile header displays `Kentstown, Ireland` on both the map overlay and the user bio section on desktop.
**Actual behavior:** Profile header map overlay displayed only `Ireland` and omitted the city name on desktop layout.

## 🩺 Root Cause

`profile-header.tsx` rendered `{displayCountryName}` exclusively on top of the map card overlay (`line 1010`), ignoring `{displayCityName}`. Furthermore, the detailed location string `{displayCityName}, {displayCountryName}` was wrapped inside a mobile-only block (`sm:hidden`).

## 🛠️ Resolution

1. Updated the map card overlay heading in `profile-header.tsx` to render `{displayCityName}, {displayCountryName}` when both city and country are present.
2. Added a responsive desktop location container (`hidden sm:flex`) in `profile-header.tsx` under the user info/bio section.
